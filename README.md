# Liquid Launcher

An iOS-inspired Android home launcher with a translucent dock, searchable installed apps, and a simulated lock-screen preview. Written in Kotlin and Jetpack Compose.

## Build without Android Studio

Go to **Actions → Build Android APK → Run workflow**. After a successful run, download the **LiquidLauncher-debug-apk** artifact and unzip it to get the APK.

The lock screen is only an in-app preview; Android's secure lock screen remains active. This is a prototype and has not been verified on a physical Android device.
